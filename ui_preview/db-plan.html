아이스크림 프로젝트 DB 설계안

관리자 페이지를 만들기 전에 어떤 데이터를 저장할지 함께 검토하기 위한 문서입니다. 실제 관리자 UI나 데이터베이스는 아직 구현하지 않았습니다.

DB 종류SQLite 파일 1개로 시작
1차 범위관리자 · 주문 · 재고
추후 확장로봇 로그 · 설정 · 통계

전체 구성

주문 화면→ice_cream.db←관리자 페이지

1. admins 필수

관리자 로그인과 권한을 관리합니다.

필드저장 내용
id관리자 고유 번호
username로그인 아이디
password_hash해시 처리된 비밀번호
name관리자 이름
role관리자 권한 구분
is_active계정 활성화 여부
created_at계정 생성 시각
last_login_at마지막 로그인 시각

2. orders 필수

고객 주문과 로봇 제조 결과를 기록합니다.

필드저장 내용
id주문 번호
flavor선택한 아이스크림 맛
status대기 · 제작 중 · 완료 · 실패
ordered_at주문 접수 시각
started_at로봇 작업 시작 시각
completed_at작업 완료 시각
error_message실패한 경우 오류 내용

3. inventory 필수

맛별 재고와 주문 가능 여부를 관리합니다.

필드저장 내용
id재고 항목 번호
flavor아이스크림 맛 이름
remaining_count현재 제조 가능한 잔여 수량
is_available사용자 화면에서 주문 가능한지 여부
updated_at마지막 재고 변경 시각

추후 추가 후보

테이블용도
robot_logs로봇 작업, 경고 및 오류 기록
settings제조 시간, 운영 상태 등 시스템 설정

보안 원칙: 관리자 비밀번호 원문은 저장하지 않고 안전하게 해시 처리한 값만 DB에 저장합니다.
